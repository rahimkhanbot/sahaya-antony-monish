# Sahaya Antony Monish — Static Site

Static one-page version of `sahayaantonymonish.com`, built with plain HTML and CSS for simple deployment to GitHub Pages, Cloudflare Pages, or any static host.

## Preview locally

```powershell
python -m http.server 4173 --directory dist
```

Then open `http://localhost:4173`.

## Deploy

Use `dist` as the Cloudflare Pages build output directory. No build command is required.
